## 8. Seed analysis

The seed question must be separated into four layers.

### 8.1 Type ambiguity

The rank-one forms

\[
P_{\mathrm{bil}}(xe,ye)=\alpha xy,
\qquad
P_{\mathrm{sesq}}(xe,ye)=\alpha\overline{x}y
\]

can both satisfy `P(e,e)=1` with `alpha=1`, while differing at `(ie,e)`.

This proves type ambiguity under the local normalization.

### 8.2 Seed ambiguity within a fixed type

Inside the fixed one-dimensional bilinear type with a fixed basis `e`, every bilinear form has the shape `alpha xy`. The condition `P(e,e)=1` forces `alpha=1`.

Inside the fixed one-dimensional conjugate-sesquilinear type with fixed basis and convention, every form has the shape `alpha conjugate(x)y`. The same normalization forces `alpha=1`.

Thus:

```text
RANK-ONE SEED WITHIN FIXED BILINEAR TYPE AND FIXED BASIS: UNIQUE
RANK-ONE SEED WITHIN FIXED SESQUILINEAR TYPE AND FIXED BASIS: UNIQUE
SAME-TYPE SEED NONUNIQUENESS: NOT PROVED
```

### 8.3 Basis presentation freedom

Changing the basis changes the displayed coefficient. In the bilinear branch, `e' = s e` gives

\[
P(e',e')=s^2P(e,e).
\]

In the Hermitian convention it gives

\[
P(e',e')=\overline{s}sP(e,e).
\]

This is presentation freedom, not automatically a distinct retained seed.

### 8.4 Gauge equivalence

The current law says raw matrices are not retained truth, but it does not yet define the primary-pairing gauge action tightly enough to decide which seed presentations are equivalent.

### 9.2 Left, right, and two-sided orthogonality

For a nonsymmetric pairing `P`, the following are distinct:

\[
P(x_{\mathrm{old}},x_{\mathrm{new}})=0
\quad\text{(right orthogonality)},
\]

\[
P(x_{\mathrm{new}},x_{\mathrm{old}})=0
\quad\text{(left orthogonality)}.
\]

Two-sided orthogonality requires both.

The exact matrix

\[
M=
\begin{pmatrix}
1&1\\
0&2
\end{pmatrix}
\]

has `P(new,old)=0` but `P(old,new)=1`. One-sided orthogonality therefore does not force both mixed blocks to vanish.
