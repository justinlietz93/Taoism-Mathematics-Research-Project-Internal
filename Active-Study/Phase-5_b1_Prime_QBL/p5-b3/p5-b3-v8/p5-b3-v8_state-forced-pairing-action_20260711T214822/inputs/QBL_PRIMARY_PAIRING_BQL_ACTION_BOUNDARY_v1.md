## 4. Source-forced two-slot interface

### 4.1 Pairing object before realization

At every primitive prefix `W_t`, the authority requires one primary object

\[
P_t\in\operatorname{Pair}_2(\mathsf H_t^{(1)},\mathsf H_t^{(2)}).
\]

`Pair_2` is intentionally realization-neutral. It means:

1. `P_t` has two ordered argument positions;
2. both same-chart restrictions and both mixed transfers descend from this one object;
3. the object depends on the advanced retained custody state and exact word prefix;
4. it mutates at every primitive tick;
5. it is retained before terminal projection.

This does **not** yet mean

\[
P_t:\mathsf H_t\to D(\mathsf H_t),
\]

nor

\[
P_t:\mathsf H_t\times\mathsf H_t\to K.
\]

Those are candidate realizations.

### 4.2 Pullback interface

The primary law gives the intended chart-side shape

\[
\Omega_t^+=\iota_+^*P_t\iota_+,
\qquad
\Omega_t^-=\iota_-^*P_t\iota_-,
\]

\[
T_t^{+\to-}=\iota_-^*P_t\iota_+,
\qquad
T_t^{-\to+}=\iota_+^*P_t\iota_-.
\]

The exact source passage immediately says these equations state the direction of construction and that the exact chart-map recurrence remains a formalization obligation.

Therefore the source forces an abstract two-slot restriction operation

\[
\operatorname{Res}_{a,b}(P_t),\qquad a,b\in\{+,-\},
\]

but it does not type `*`. In particular, `*` is not yet proved to mean transpose, conjugate transpose, dual precomposition, an adjoint, or a categorical involution.

### 4.3 Architectural rank

The seed architecture has one active axis. `B` and `Q` do not change rank. Each `L` increases rank by one. Thus

\[
\boxed{r_t^{\mathrm{arch}}=A_t+1.}
\]

This is not an algebraic rank theorem. It counts retained architectural axes.

### 4.4 Exact-word dependence

The source says `P_t` is generated from the retained state and exact ordered word. Hence operation counts are insufficient. The lawful abstract recurrence must be prefix-sensitive:

\[
P_{t+1}=\mathfrak U_{U_t}(P_t;X_{t+1},W_{t+1}),
\qquad U_t\in\{B,Q,L\}.
\]

The maps `mathfrak U` are required to exist at the architectural level, but their value laws are open.
