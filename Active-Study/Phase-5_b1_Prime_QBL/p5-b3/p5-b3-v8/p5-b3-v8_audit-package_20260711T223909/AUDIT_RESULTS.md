## Defect 1: PPGRL is the whole missing solution, not the first missing datum

The document defines `PPGRL` as the function that returns the next primary pairing, all four restriction maps, the seed, every `B/Q/L` case, and all first-`L` components. It then calls `PPGRL` the first missing bridge.

That is circular as a minimal-boundary claim. `PPGRL` is a useful name for the complete unresolved deliverable. It does not identify the first retained distinction, type law, factorization theorem, or structural map needed to derive that deliverable.

The package itself lists several logically prior unknowns:

```text
argument-object architecture
pairing carrier and codomain
chart embeddings or placement maps
restriction constructor
seed law
B/Q/L primary update
L old/new component law
action-equivalence category
```

Until their dependency order is settled, `PPGRL` cannot be ratified as the first missing datum.

## Defect 2: the descendant equation is formally vacuous without a non-smuggling condition

The package requires

\[
D_{ab,t+1}=R_{ab,t+1}(P_{t+1}),
\]

while allowing each `R_{ab,t+1}` to be produced alongside `P_{t+1}` by `PPGRL`.

This does not by itself prove that the descendants are generated by the primary pairing. Given any independently chosen target descendant `d_ab`, define the constant map

\[
R_{ab,t+1}(P)=d_{ab}.
\]

Then the displayed equation holds for every `P`, even though the descendant value was selected independently. The package's independent-descendant negative control can therefore be repackaged to satisfy the formal equation unless an additional factorization constraint excludes constant-map smuggling.

A lawful dependency certificate must separate:

1. the retained argument architecture and chart placements;
2. the primary pairing object;
3. a fixed restriction constructor appropriate to the realization;
4. the four descendants obtained by applying that constructor.

At minimum, identical primary objects and identical structural placement data must force identical descendants. Restriction maps may not encode independently selected target values.
