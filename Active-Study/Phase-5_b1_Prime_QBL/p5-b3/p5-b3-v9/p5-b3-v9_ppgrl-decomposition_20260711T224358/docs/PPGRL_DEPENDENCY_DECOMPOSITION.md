# PPGRL Dependency Decomposition

## Purpose

`PPGRL` names the complete unresolved primary-pairing generation and restriction program. It is not one datum. The dependency chain below separates its obligations so the first missing datum is visible.

## Dependency order

| Order | Obligation | Current status | Exact dependency |
|---:|---|---|---|
| 0 | Custody state and exact ordered word | **PROVED** | Primitive law Sections 1–10 |
| 1 | Source-forced two-slot architectural skeleton | **PROVED** | Two orientation hands, four ordered placements, fixed architectural rank under `B/Q`, old/new extension under `L` |
| 2 | Exact state-indexed argument-and-placement realization | **OPEN** | Must provide ambient argument object(s), chart argument objects, `iota_+`, `iota_-`, `B/Q` transport, and `L` old/new embeddings at every prefix |
| 3 | Primary pairing carrier, codomain, and evaluation notion | **OPEN** | Cannot be typed before Order 2 |
| 4 | Non-vacuous restriction constructor | **ABSTRACT INTERFACE PROVED; QBL INSTANTIATION OPEN** | Pointwise restriction through the placements; depends on Orders 2–3 |
| 5 | Primary seed | **OPEN** | Depends on Orders 2–4 |
| 6 | Intrinsic `B` update | **PARTIAL SIGNATURE PROVED; VALUE LAW OPEN** | Depends on seed and state-to-primary generator |
| 7 | Intrinsic `Q` update | **PARTIAL SIGNATURE PROVED; ACTION TYPE OPEN** | Depends on argument action, pairing action, and restriction constructor |
| 8 | Intrinsic `L` old/new extension | **OLD-OLD RETENTION PROVED; MIXED/NEW-NEW OPEN** | Depends on old/new embeddings, codomain transport, and primary generator |
| 9 | Action-equivalence category | **ABSTRACT CRITERION PROVED; CONCRETE CATEGORY OPEN** | Depends on the exact realization types and all case maps |

## Earliest missing datum

```text
STATE-INDEXED ARGUMENT-AND-PLACEMENT REALIZATION
```

It must determine, from the retained custody state and exact word prefix:

```text
ambient two-slot argument architecture
plus-chart argument object and placement iota_+
minus-chart argument object and placement iota_-
B/Q transport of those placements
L old-sector embedding and newborn-sector placement
```

Without this datum, the primary pairing has no exact domain, the four restrictions have no exact source objects, and the old/new component laws cannot be typed. Naming the complete `PPGRL` program does not remove this earlier obligation.
