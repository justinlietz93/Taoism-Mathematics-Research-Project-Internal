## Load-bearing defect: `M` is only a pairwise envelope

The package treats

```text
M = [[0,1,1],
     [1,1,1],
     [1,1,0]]
```

as the adjacency matrix of the full carry language. It records only which adjacent pairs have positive one-step mass.

The word `989` is admitted by this graph because `9->8` and `8->9` each have positive `J` mass. The actual interval system forbids the three-symbol word.

After the prefix `9->8`, the current-state interval is

```text
F9(I9) intersect I8 = (-1/2-a, -1+2a].
```

Applying `F8(x)=2x+2a` gives

```text
(-1, -2+6a].
```

For `a<1/4`,

```text
-2+6a < -a,
```

so the image lies strictly left of `I9=(-a,0]`. Therefore `989` has empty cylinder.

At the actual parameter, `787` is also absent. Its exclusion uses the stronger numerical fact `a>3/14`, not merely the broad lock `1/6<a<1/4`.

## Consequences

### `P` is not an established first-order Markov presentation

`P` is a correct one-step conditional probability table under Lebesgue measure. A first-order Markov chain with both `P[9,8]>0` and `P[8,9]>0` assigns positive probability to `989`. The interval process assigns zero probability. Therefore the full carry process is not represented by `P` as a first-order Markov chain.

### `log(1+sqrt(2))` is not the established entropy of the carry coding

That value is the entropy of the edge shift generated by `M`. It is larger than `log(2)`. The carry itinerary is a factor of a degree-two affine doubling map, so its coding entropy cannot exceed `log(2)`. The source package therefore assigns the edge-envelope entropy to the wrong object.

### `K` is not the established Parry measure of the actual carry coding

The formula for `K` is algebraically correct for the edge shift defined by `M`. It must be relabeled:

```text
PARRY JOINT EDGE MEASURE OF THE PAIRWISE EDGE-SHIFT ENVELOPE
```

The empirical comparison against `K` remains numerically correct, but it is a comparison against an over-approximating baseline.

### Primitivity does not transfer from the envelope

`M^2>0` proves that the pairwise edge-shift envelope is mixing. It does not prove that the actual higher-order constrained carry language is mixing.
