# Source Alignment

This package implements the recovered Phase 5 target that B refinement must be operational over arbitrary carried starts, not only the canonical Fibonacci origin corridor.

Alignment:

```text
B is treated as a retained pair operation.
The canonical Fibonacci origin is one admitted start.
Arbitrary 1/n and asymmetric coprime starts are admitted if the support gates pass.
Terminal projection signatures are not treated as state-complete.
```
