
## Native Phase 5 closure

Native Phase 5 closure means the Orthad retained-history pipeline is specified, tested, and guarded against known label drift. It does not mean universal external FQM classification.

## Hard scope boundary

A hard scope boundary must name why a target is not part of Phase 5's native mechanism. It cannot say only that the target is a later theorem surface.
