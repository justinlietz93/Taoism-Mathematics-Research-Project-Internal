# Primary Pairing Seed

```text
PRIMARY_PAIRING_SEED: NOT_YET_DERIVED
MISSING_MAP: eta_P : (Xi_0,W_0,D_P) -> P_0
```

The initial custody state fixes no coefficient object and no pairing value. Distinct forms can share the same custody tuple. A constant chart matrix, imported Weil operator, finished FQM form, Bloch coordinate, terminal character, affine coordinate, or `Z/12Z` skeleton is not a lawful seed without a derivation.
