## Research result

The weakest interface forced by the written architecture is a primary two-slot pairing system:

```text
P_t ∈ Pair(H_t,H_t)

(f,g)*:
Pair(A,B) -> Pair(A',B')
for f:A'->A and g:B'->B
```

This directly types both chart restrictions and both directed transfers. At this layer, `*` means first-slot pullback notation. It is not yet an adjoint, conjugation, transpose, or scalar involution.

The represented model

```text
P_t : H_t -> D(H_t)
```

requires an additional axiom:

```text
For every H, there exists D(H) and a natural isomorphism

Pair(A,H) ≅ Hom(A,D(H))

compatible with pullback in both arguments.
```

No source supplies that representability axiom.

At the first `L`, the strongest licensed block schema is:

```text
[[P_t,    C_right],
 [C_left, p_new ]]
```

The source does not define orthogonality as left, right, or two-sided. The explicit nonsymmetric example

```text
[[1,1],
 [0,1]]
```

has `P(new,old)=0` and `P(old,new)=1`, proving that one-sided orthogonality does not force both mixed blocks to vanish.

The architectural axis count increases `1 -> 2`. Algebraic pairing rank is not implied: `diag(1,0)` has block size two but rank one.
