# L pairing type signature

Derived at the minimal interface level:

```text
Phi_L^P : P_t in Hom(H_t,D(H_t))
          -> P_(t+1) in Hom(H_t direct_sum A_new, D(H_t direct_sum A_new))
```

The old restriction equals `P_t`. Two-sided orthogonality of `A_new` to `H_t` forces both mixed birth maps to zero. The new-axis self-pairing remains open.

```text
P_(t+1) = block_diag(P_t, p_new)
```
