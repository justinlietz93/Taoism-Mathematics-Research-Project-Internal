# Q pairing type signature

Derived at the minimal interface level:

```text
Phi_Q^P : (Xi_t, Xi_(t+1), W_(t+1), P_t, J_active)
          -> P_(t+1) in Hom(H_t,D(H_t))
```

`J_active^2=-id` realizes the quarter-turn at fixed retained argument object. Whether it acts by coefficient multiplication, argument conjugation, or another covariant update is open.
