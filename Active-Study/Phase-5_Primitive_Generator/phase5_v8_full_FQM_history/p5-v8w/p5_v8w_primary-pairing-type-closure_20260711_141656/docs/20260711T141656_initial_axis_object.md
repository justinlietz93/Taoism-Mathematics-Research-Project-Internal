# Initial Axis Object

Source-derived:

- one architectural active-axis slot exists before the first `L`;
- that slot is latched at `L`;
- one new architectural slot is appended;
- the pairing's relative rank obligation changes by one.

Not source-derived:

- that the slot is a basis vector;
- that `H_0` is one-dimensional;
- that `P_0` has rank one;
- that either chart has one coordinate.

A free-module model generated by axis slots is admissible, but remains a candidate formalization.
