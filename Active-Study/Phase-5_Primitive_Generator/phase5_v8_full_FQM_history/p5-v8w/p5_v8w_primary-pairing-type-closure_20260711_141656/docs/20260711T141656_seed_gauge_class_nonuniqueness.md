# Seed Gauge-Class Nonuniqueness

Gauge equivalence is defined at the abstract interface by

```text
P ~ P' iff P' = D(U) P U for an automorphism U of H.
```

A model witness uses `H=C`, quarter-turn `J(x)=ix`, and the pairings `P_zero=[0]` and `P_unit=[1]`. Their ranks differ, so no invertible congruence relates them. Both admit a block-diagonal first-L extension.

This proves gauge-class nonuniqueness **inside the unconstrained minimal interface**. It does not prove that both are admissible retained seeds, because the clean law does not specify seed rank, nondegeneracy, or normalization.
