# B/Q successor covariance

Every pre-L prefix was processed in order. The carrier-level local surface remains `C_0 = Z/12Z`, but no clean `S_t` is available at any prefix.

The sources do not choose among:

1. changing `S_t` under `B/Q`;
2. conjugating `S_t`;
3. keeping `S_t` while changing its eigencharacters/eigenform;
4. keeping a fixed historical shift while another retained object mutates.

The last case describes the available v7c computation, but v7c has no clean QBL covariance. The stronger clean typing is a word-covariant system `(C_t,S_t,alpha_t)`. Its first missing square occurs at the first `B`.
