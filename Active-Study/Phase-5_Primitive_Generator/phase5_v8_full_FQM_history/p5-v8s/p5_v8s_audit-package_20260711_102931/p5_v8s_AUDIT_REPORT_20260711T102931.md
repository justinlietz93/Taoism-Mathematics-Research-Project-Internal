## Adopted findings

### A1. Primitive baseline remains sound

The package reuses and sanity-checks the accepted first crossing:

```text
BQQBBBQBQBBQBBL
```

It retains `(55,89)`, five quarter turns, first-L carry, and the first next-domain `B` to `(89,144)`.

### A2. The local scalar is correctly demoted

The package classifies

```text
a_t = i^(local_Q)/(u_t v_t)
```

as `LOCAL_DESCENDANT_ONLY`. It is not promoted to either chart restriction, the primary pairing, or an invariant of the complete Orthad.

### A3. Historical `O` is assessed by semantics

The package correctly distinguishes:

```text
O as a derived overlap-support record
from
O as a custody primitive
```

It also finds that `v7u` appends overlap records after the Q/B/L histories rather than deriving an overlap update inside every clean primitive transition. The modern schedule remains open.

### A4. `pair_c` has exact defects

The historical formula is code-defined, not derived from the clean pairing-first law. It includes an explicit branch that changes a computed zero residue to one and is evaluated only in post-hoc overlap records. Rejecting it as the modern coupling law is justified.

### A5. The broad bilinear nonuniqueness point is correct

The package proves that two symmetric bilinear forms can have the same two diagonal chart restrictions and different mixed terms. This establishes that diagonal restrictions alone do not determine transfer.

The current example uses one degenerate form. That is enough for the broad theorem as stated, but not for a stronger claim inside a nondegenerate admissible class. A stronger witness is available with matrices

```text
[[1,0],[0,1]]
[[1,2],[2,1]]
```

which have the same diagonal restrictions, different mixed terms, and nonzero determinants over `Q`.

### A6. Downstream restraint is correct

No pairing matrix, chart matrix, transfer matrix, projection row, gauge quotient, FQM object, or Weil descent is emitted. That hard stop is appropriate while the internal recurrence is open.

## Findings requiring revision

### F1. The response ZIP hash does not identify the supplied file

The exact linked/delivered ZIP must be hashed after sealing. The declared SHA-256 differs from the archive supplied for audit.

### F2. The claimed earliest gap omits the native successor

The canonical generative direction says:

```text
primary pairing = forced object / eigenbasis of the native successor
```

The package does not define, inventory, search for, or mark open any `S_t` native-successor operator. Its type table jumps directly from custody to an invented ambient module functor:

```text
H : (X_t,W_t) -> (R,H_t,basis_t,Phi_B^H,Phi_Q^H,Phi_L^H)
```

That functor may become a useful formal presentation, but the package has not shown that it is required by canon or that it precedes the native successor. The correct current disposition is:

```text
AMBIENT_RETAINED_MODULE_FUNCTOR: CANDIDATE_FORMALIZATION
EARLIEST_TYPED_OR_OPERATIONAL_GAP: NOT_YET_ISOLATED
```

The next pass must determine whether the retained axis stack, doubled orientation carrier, and native successor already give the concrete carrier and basis without introducing `H_t` as a new primitive object.

### F3. `FULL_CITED_SOURCE_LINEAGE: PASS` is too broad

The requested Phase-5 artifacts `v7p`, `v7q`, `v7m`, `v7u`, and `v8a` are present. The historical source corpus `orthad_overset_grids.zip` is not present; only its manifest and recorded hash are available.

Use two statuses:

```text
SPECIFIED_PHASE5_ARTIFACT_LINEAGE: PASS
EXTERNAL_OVERSET_SOURCE_CORPUS: INCOMPLETE
```

The conclusion may say that the **available Phase-5 corpus** does not force the recurrence. It may not say the complete cited corpus has been exhausted.

### F4. The historical `L` transition is rejected for the wrong reason

The source-claim matrix says the newborn scalar axis conflicts with clean carry because it starts at identity. This collapses local and global state.

The clean law allows:

```text
global pair and phase: carried unchanged
new local active axis: initialized to identity
```

Therefore `lens_newborn/lens_latched` is not invalid merely because the newborn local slot is `1`. Its actual limitation is that it is a historical cross-axis scalar ratio, not a primary-pairing update or cross-chart transfer derived from the modern Orthad.

Correct disposition:

```text
HISTORICAL_L_SCALAR_RATIO: CONDITIONALLY_LICENSED_IN_OLD_LOCAL_MODEL
MODERN_L_PAIRING_OR_TRANSFER_LAW: NOT_YET_DERIVED
```

### F5. Three passing tests certify withdrawn claims

`tests/test_recurrence_boundary.py` still asserts:

The `p5_v8s` response explicitly withdraws those claims. Thus `18 passed` contains three semantically stale passes. They must be removed, quarantined as provenance, or rewritten against the current boundary.

### F6. The corruption-control claim is false and non-reproducible

The response reports:

```text
corruption controls: 16/16
```

The package contains one CSV with **12** controls. No package script creates or executes those controls. The rows are static declarations and are excluded from the reproducibility comparison.

Required repair:

```text
run each mutation in a temporary copy
invoke the real verifier
record target gate, observed exit code, and evidence diff
compute the count from those executions
```

### F7. The verifier is not directly runnable on a normal extraction

Running the verifier normally imports Python modules and creates `__pycache__`; running pytest creates `.pytest_cache`. The verifier then encounters these unmanifested paths and can fail with a `KeyError`. It succeeds only when the caller supplies special environment controls and cleans the tree first.

A sealed verifier must not invalidate its own input. It should disable bytecode internally, avoid pytest cache creation, and verify the ZIP in a fresh temporary extraction.

### F8. The verifier hard-codes the conclusions it claims to certify

Examples:

```text
earliest_gap gate == ambient_retained_module_functor
full_cited_lineage gate passes when the five requested folders exist and the external archive is marked unavailable
```

These are report-consistency gates, not source-insufficiency proofs. They must be labeled accordingly and separated from independent source checks.

### F9. The first-L rank statement is partly schematic

The axis-block count changes from one to two. That structural obligation is ratified. Since `P_t` itself remains untyped, the package should not present `rank(P_t)=1 -> 2` as an algebraic fact already instantiated. Use:

```text
RETAINED_AXIS_BLOCK_COUNT: 1 -> 2
PAIRING_RANK_REALIZATION: NOT_YET_DERIVED
```
