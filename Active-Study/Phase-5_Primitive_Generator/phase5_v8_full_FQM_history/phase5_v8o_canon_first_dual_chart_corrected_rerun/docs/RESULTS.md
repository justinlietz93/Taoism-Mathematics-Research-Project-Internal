# Results

The baseline emits both lens matrices and both directed transfer matrices. The domain is empty before the word and is emitted only after B compiles the chart overlap field. L freezes the `(55,89)` axis, records `i/4895`, creates the next axis, applies the doubled-hand transport, and checks `lap2=-lap1`.

Every required ablation makes the evidence-recomputed survival gate fail:

- delete B
- delete L
- replace pair with `(1,1)`
- replace pair with `(100,101)`
- corrupt retained floor bit
- corrupt latched axis
- sever cross-chart transfer

`corrupt_floor_bit` changes field custody without changing the lens matrices; its Omega diff is correctly zero while the survival gate fails. `sever_cross_transfer` changes only the off-diagonal transfer block.
