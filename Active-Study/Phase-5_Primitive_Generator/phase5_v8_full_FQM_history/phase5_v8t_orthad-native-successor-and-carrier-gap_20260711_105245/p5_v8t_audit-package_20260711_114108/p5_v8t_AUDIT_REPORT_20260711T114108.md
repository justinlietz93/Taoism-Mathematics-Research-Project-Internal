## Findings requiring revision

### F1. `Z/12Z × Z/24Z` is not yet a derived clean retained carrier

The package defines:

```text
C_{<=A} = product_{r=0..A} Z/(2N_r)Z
```

by combining three statements:

1. Domain `A` has `N_A=6*2^A` phase positions.
2. A cyclic base `N` uses doubled carrier `Z/(2N)Z`.
3. Historical v7d supports products of independent cyclic axes.

The bridge between them is not proved.

The clean law ratifies one retained old axis plus one newborn axis at the first `L`. It does not state that the underlying carrier group is the direct product of one factor for every domain. The historical v7d result assumes independent cyclic axes and then tests a product FQM. Its formal surface records the central direct-sum claim as an axiom, and the result was produced under the older Orthad interpretation.

At the first `L`, the inherited and newborn axes are not shown to be independent. The possible carrier-level constructions still include:

```text
Z/12Z × Z/24Z
an extension of Z/24Z by Z/12Z
a single retained carrier with a two-block axis presentation
another word-built coupled carrier
```

Correct status:

```text
DOMAIN0_DOUBLED_CYCLIC_SURFACE: SUPPORTED
FIRST_L_AXIS_BLOCK_COUNT: 1 -> 2
FIRST_L_PRODUCT_CARRIER: NOT_YET_DERIVED
CANDIDATE_PRODUCT_INDEX_SET: Z/12Z × Z/24Z
```

The prefix table is therefore a candidate table generated from the package's product formula, not a certificate of the clean carrier recurrence.

### F2. The table does not derive retained doubled addresses

### F3. `Phi_L^S` cannot be the earliest missing successor map

The package says the first exact gap is:

```text

```

but also admits that `Phi_B^S` and `Phi_Q^S` are absent.

```text

Phi_B^S at the first B
Phi_Q^S at the first Q
all later pre-L B/Q updates
```

The fixed historical shift `s_12` is not yet proved to be `S_empty`. If it is accepted as a seed, the first missing chronological map is the first `B` update, not `L`.

### F4. The ambient module is not merely optional

The package is correct that an abstract module functor is not a new custody primitive and need not precede the successor as an operational object.

But an eigenbasis, eigenform, Fourier kernel, and bilinear pairing require a linear or module representation over a coefficient ring or field. The formal layer is therefore required before the canon phrase `pairing = eigenbasis/eigenform of the native successor` can be typed.

Use:

```text
AMBIENT_SPECTRAL_MODULE_ROLE:
REQUIRED_FOR_EIGENBASIS_AND_PAIRING_FORMALIZATION
NOT_THE_EARLIEST_CUSTODY_OPERATIONAL_GAP
```

rather than `OPTIONAL_FORMAL_PRESENTATION`.

### F5. The v7e first-L rejection uses a false supporting reason

The package says that giving the newborn axis `q_j=0` would be invented. The historical v7e tests explicitly allow zero retained Q-depth on an axis and use `(q+1)` in the extractor.

The real problem is different. At the first clean `L`, the newborn axis did not exist before the latch, while v7e's shared-boundary extractor was defined for two axis histories that both existed before one shared latch event.

The next pass should determine whether first-axis birth has a lawful boundary-incidence analogue rather than rejecting the clue because of zero depth.

The `CONCRETE_CARRIER_PREFIX_TABLE`, `SUCCESSOR_HARD_STOP`, and `AMBIENT_ROLE` gates recompute the package's own formulas and expected labels. They show reproducibility and internal consistency. They do not prove that the product carrier formula is licensed by clean canon.
