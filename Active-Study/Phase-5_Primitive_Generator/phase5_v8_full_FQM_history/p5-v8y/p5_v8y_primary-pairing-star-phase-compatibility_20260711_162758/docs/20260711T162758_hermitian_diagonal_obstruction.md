# Hermitian diagonal obstruction

Let `h` be Hermitian. Then

`h(x,x) = conjugate(h(x,x))`,

so every diagonal self-pairing is fixed by conjugation. For `uv != 0`,

`conjugate(i/uv) = -i/uv != i/uv`.

At the accepted first boundary `uv=4895`, the difference is `2i/4895`.

This proves only:

```text
HERMITIAN DIAGONAL PROMOTION OF i/(uv): REJECTED
```

It does not reject a Hermitian primary object whose local shorthand is an off-diagonal, projected, or otherwise descended quantity.
