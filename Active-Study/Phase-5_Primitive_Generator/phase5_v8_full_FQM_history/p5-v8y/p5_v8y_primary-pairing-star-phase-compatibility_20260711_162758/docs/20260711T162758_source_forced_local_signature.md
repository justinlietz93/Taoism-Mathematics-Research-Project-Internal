# Source-forced local signature

## Source-forced obligations

The ratified source forces only a local per-step architecture:

1. one primary object `P_t` retained with custody;
2. two chart maps or inclusions `iota_+`, `iota_-`;
3. four named descendants built from the same `P_t` and those maps;
4. a `B` mutation of the primary object and all four descendants;
5. a `Q` mutation carrying the quarter-turn witness `i` through the same layers;
6. an `L` extension that retains old content, appends one new orthogonal-axis obligation, and extends the four descendants.

The source does not define a category-wide `Pair(-,-)` bifunctor, functorial identity/composition laws, a coefficient ring, or the meaning of `*`.

## Candidate realization

A two-slot pullback system or a represented morphism `H -> D(H)` can model the obligations, but neither is source-forced.
