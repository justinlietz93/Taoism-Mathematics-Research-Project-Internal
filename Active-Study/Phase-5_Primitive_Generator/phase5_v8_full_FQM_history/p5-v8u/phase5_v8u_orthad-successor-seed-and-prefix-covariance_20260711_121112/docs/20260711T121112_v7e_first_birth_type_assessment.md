# v7e first-birth type assessment

`q=0` is lawful in v7e. The extractor explicitly uses `(q_i+1)(q_j+1)` and includes tested histories with zero retained Q-depth.

The type failure at the first clean `L` is not zero depth. The v7e input contains two axis histories that both exist before a shared latch. At first axis birth, the newborn axis has no pre-latch history.

A lawful modern analogue could use incidence between the completed old-axis boundary and a newborn-axis germ, but that requires a new birth-incidence map. v7e does not supply it and is not promoted to a modern pairing or transfer law.
