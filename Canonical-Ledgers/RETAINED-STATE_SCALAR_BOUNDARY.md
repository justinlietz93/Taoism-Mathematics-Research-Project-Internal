# RETAINED-STATE SCALAR BOUNDARY

Keep algebraic representation separate from retained ontology.

No static scalar is an independent component of the retained lifted state.

Scalar coefficients may appear inside a lawful algebraic presentation of:

[
P_t,\quad
\Omega_t^\pm,\quad
T_t^{\pm\to\mp}.
]

Those coefficients are coordinates of a representation. They are not the complete retained object.

A scalar such as

[
a_t=\frac{i^{#Q(W_t)}}{u_tv_t}
]

or

[
a_{\mathrm{completed},0}=\frac{i}{4895}
]

is a derived local trace. It may test a candidate recurrence, but it may not replace the primary pairing, chart restrictions, directed transfers, or retained history.

When considering a coefficient system, determine whether it is required only to express a candidate representation. Do not treat it as an added state coordinate or as primitive retained truth.

Use these statuses:

```text
STATIC SCALAR IN RETAINED STATE:
    NOT LICENSED

ALGEBRAIC REPRESENTATION WITH SCALAR COEFFICIENTS:
    ALLOWED

SCALAR-VALUED PRIMARY PAIRING:
    NOT YET DERIVED

LOCAL SCALAR TRACE:
    ALLOWED BUT STATE-INCOMPLETE

TERMINAL SCALAR OR CHANNEL:
    PROJECTION-SIDE DESCENDANT
```

Assess every proposed scalar by stating which of these roles it occupies.
