# p5-salvage-v1 Orthad Current-Canon Extraction

This package pauses forward derivation and separates the Phase 5 history into current-canon results, conditional mathematics, calibration/obstruction data, supplemental tools, historical analogues, superseded claims, and invalid certificates.

Start here:

1. `docs/SALVAGE_REPORT.md`
2. `docs/CURRENT_CANON_BASELINE.md`
3. `ledger/SALVAGE_LEDGER.csv`
4. `docs/CANONICAL_RESEARCH_TRUNK.md`
5. `docs/CONDITIONAL_PIPELINES.md`
6. `docs/CALIBRATION_AND_OBSTRUCTIONS.md`
7. `docs/TOOLING_AND_INSTRUMENTATION.md`
8. `docs/PROVENANCE_GAPS.md`

The package classifies 65 legacy package units. It does not claim that every line of every legacy file was independently re-proved. It does bind the disposition to the result cards, later external audits, and current authority, and it carries the highest-value original evidence and tools.

Run:

```bash
python scripts/verify_salvage.py .
```
