# Provenance Gaps to Close

The legacy downstream mathematics can be promoted only by closing these explicit edges.

## Edge 1: retained state to primary pairing

Derive the type, seed, and exact `B/Q/L` update of `P_t`.

## Edge 2: primary pairing to four descendants

Derive the exact chart placement/restriction and directed-transfer laws without independent target smuggling.

## Edge 3: descendants to event/transition records

Show that the legacy v7p/v7q alphabet and T records are generated from the current descendants, or define a corrected replacement.

## Edge 4: transition records to FQM

Re-run v7t/v7u and the v8 classifier pipeline on records generated through Edges 1-3.

## Edge 5: FQM to finite shadow target

Only after Edge 4 may the finite `chi12` and Weil identities be called generated projections rather than calibration targets.

A failure at any edge does not invalidate the downstream mathematics. It changes its status from canonical output to external tool or comparison model.
