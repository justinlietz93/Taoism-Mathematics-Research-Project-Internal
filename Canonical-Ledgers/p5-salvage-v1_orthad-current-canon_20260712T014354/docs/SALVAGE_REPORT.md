## Verdict

The legacy corpus contains substantial valid mathematics. It also contains several false closure claims, successor-first drift, noncanonical one-crossing models, and certificates that did not prove what their labels claimed. The correct action is selective reconstruction, not deletion.

The salvage ledger separates every package into:

```text
A  current-canon theorem or constraint
B  correct conditional theorem or reusable pipeline
C  exact calibration, counterexample, or obstruction
D  historical conjecture, external analogue, or research index
E  superseded or false conclusion
F  invalid or non-probative certificate
```

Primary dispositions in this release:

```text
A: 11
B: 20
C: 23
D: 6
E: 4
F: 1
```

A package can contain useful secondary material even when its headline is class E or F. The ledger records both the retained content and the excluded conclusion.

## Reconstruction boundary

The downstream corpus can rejoin the canonical chain only through an explicit provenance bridge:

```text
clean retained prefix Xhat_t
-> exact primary pairing P_t
-> exact chart restrictions and transfers
-> exact transition/event record
-> finite quadratic presentation
-> classifier/decomposition/calibration result
```

The first three arrows remain open. Therefore this salvage package preserves downstream work without using it to fill the upstream gap.
